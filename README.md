# BMW Sales Dashboard using Power BI

## 📌 Project Overview
This project analyzes BMW sales data from 2010 to 2024 using Microsoft Power BI.

The dashboard provides business insights, sales trends, KPIs, and interactive visualizations for better decision-making.

---

## 🚀 Tools & Technologies
- Power BI
- Excel
- Data Visualization
- Data Cleaning
- Business Analytics

---

## 📊 Dashboard Features
- Yearly sales analysis
- Revenue trends
- KPI cards
- Region-wise sales
- Interactive charts and filters

---

## 📈 Insights Generated
- Identified top-performing sales years
- Compared yearly revenue growth
- Analyzed sales performance trends
